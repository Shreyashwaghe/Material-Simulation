Code to simulate recrystallization in a 2D material.

4*4 2D Material, with only 2 grain orientations - A, B. The system tries to re-crystallize to change the orientation of a grain, so to reduce the total energy of the system and leads to grain growth. The mis-orientation energy of A-A, B-B is considered to be zero, as shown in the video.
